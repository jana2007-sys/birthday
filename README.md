# 🎂 Birthday Web

A simple and interactive **Birthday Celebration Website** built using HTML and CSS.
The website is designed to create a fun and colorful birthday experience with personalized messages, images, and gift sections.

## ✨ Features

* 🎉 Birthday greeting section
* 💖 Personalized birthday message
* 📸 Birthday images
* 🎁 Interactive gift sections
* 🎨 Colorful and attractive design
* 📱 Responsive layout for different screen sizes
* ✨ Custom fonts and styling

## 🛠️ Technologies Used

* **HTML5** – Structure of the website
* **CSS3** – Styling, layout, colors, and animations
* **Google Fonts** – Custom typography

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

### 2. Open the project folder

```bash
cd birthday-web
```

### 3. Run the website

Open `index.html` in your browser.

You can also use **VS Code + Live Server** to run the website.

## 🎨 Customization

You can personalize the website by changing:

* Birthday person's name
* Age
* Birthday date
* Birthday messages
* Images
* Background colors
* Gift descriptions
* Fonts
* CSS animations

For example:

```html
<h1>Happy Birthday!</h1>
<p>Wishing you an amazing birthday!</p>
```
